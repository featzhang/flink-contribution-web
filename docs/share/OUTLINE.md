# Flink for AI 教程 · 内容规划（4-starter）

> 目标听众：**计算机专业硕士生**，具备编程与算法基础，但**不一定**做过数据工程 / 实时大数据。
> 形式：**HTML 幻灯片**（可键盘/点击/滑动翻页，带进场动画与逐步揭示动画），风格延续原 PPT 的
> 深色 + 紫色科技风，更炫酷、更友好。
> 改编自《腾讯基于 Flink 2.x 打造 AI 计算引擎的探索与实践》。

## 设计原则

1. **先全局，后细节**：先建立"大数据 / 数据工程 / 时代演进"的全局地图，再进入腾讯的具体实践。
2. **故事线驱动**：用"是什么 → 为什么 → 怎么演进 → 怎么落地 → 怎么共建 → 给你的建议"叙事。
3. **对比与量化**：Before/After 表格 + 真实生产数据，让抽象概念可感知。
4. **动画为内容服务**：逐步揭示（fragment）用于引导注意力，进场动画用于分隔章节，不炫技。
5. **尊重听众**：不使用"入门 / 扫盲"等字眼；每引入术语，用"💡 概念提示卡"平实补充。
